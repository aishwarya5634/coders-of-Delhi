# 🖥️ Coders of Delhi

A data analysis mini-project built as part of **[CodeWithHarry's Ultimate Job-Ready Data Science Course](https://www.codewithharry.com/)**.

---

## 📌 About the Project

**Coders of Delhi** is a beginner-friendly data analysis project that explores a dataset of programmers based in Delhi. The goal is to derive meaningful insights using **pure Python** — no pandas, no NumPy — just raw logic and Python fundamentals.

This project strengthens the foundation of data thinking, helping understand how to slice, filter, and analyze structured data manually before moving on to libraries.

---

## 🎯 Objectives

- Analyze a dataset of Delhi-based coders
- Filter and group data based on various attributes (age, language, experience, etc.)
- Answer analytical questions using only core Python
- Build logical thinking for real-world data science problems

## 🚀 How to Run

1. **Clone the repository**
```bash
   git clone https://github.com/aishwarya5634/coders-of-Delhi.git
```

2. **Navigate to the project folder**
```bash
   cd coders-of-Delhi
```

3. **Run the script**
```bash
   python coders_of_delhi.py
```
